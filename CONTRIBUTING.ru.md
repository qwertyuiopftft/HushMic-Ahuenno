# Участие в разработке

HushMic-Ahuenno — аудиопроект для Linux. Приветствуются небольшие исправления,
воспроизводимые отчёты об ошибках, улучшения совместимости с PipeWire и замеры
задержки.

Перед pull request:

1. Выполни `git diff --check`.
2. Запусти относящиеся к изменению Rust-тесты, если установлен Rust toolchain.
3. Не добавляй личные записи, эмбеддинги голоса, ключи и абсолютные локальные
   пути.
4. Для изменений аудио укажи частоту дискретизации, размер блока, версию
   PipeWire и использовался ли CPU или CUDA.

Экспериментальные модули персонализации и замены фразы должны оставаться
необязательными и не должны незаметно подменять обычный путь микрофона.
