# Безопасность и приватность

HushMic должен обрабатывать звук локально. Не публикуй в открытых issues личные
записи, enrollment-аудио, веса моделей или токены доступа. Перед прикреплением
логов удали такие данные.

Для чувствительных проблем используй приватный security advisory GitHub, если
он доступен, или свяжись с владельцем репозитория напрямую. Прикладывай только
минимальное воспроизведение и необходимые версии программ.
